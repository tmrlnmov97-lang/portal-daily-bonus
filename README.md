# Portal Games · Ежедневный бонус

Прототип экрана ежедневного бонуса для мини-приложения Portal Games в Telegram. Сделан по макету в Figma: экран «2б · Мало времени», мобайл 390 × 844.

Открыть: https://tmrlnmov97-lang.github.io/portal-daily-bonus/

- `index.html` — страница;
- `css/tokens.css` — цвета и типографика из коллекции «Portal UI» в Figma;
- `css/app.css` — вёрстка экрана;
- `js/app.js` — данные дней и отрисовка, таймер, работа внутри Telegram;
- `assets/` — арт наград и иконки, выгружены из Figma.

Сборки нет: файл открывается в браузере как есть. Внутри Telegram нарисованная шапка прячется, окно разворачивается на весь экран.
